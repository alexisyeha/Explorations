# Korean App (DoGam)

Native iOS exploration of Korean-language reading cards and a physical page-turn interaction.

- Open `DoGam/DoGam.xcodeproj` for the main app.
- Open `experiment/PageFlipPrototype.xcodeproj` for the isolated, gesture-driven paper-flip prototype.
- `experiment/PageFlipPrototype-backup-2026-09-14-220318.tar.gz` is the saved version of the prototype after the free-corner paper fold was implemented.
- `assets/`, `processed/`, `font/`, and `scripts/process_cards.py` contain the source artwork, processed card images, fonts, and image-processing script used during the exploration.

Both Xcode projects are self-contained and can be opened independently. The `project.yml` files are their XcodeGen configurations.
